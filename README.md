# Hesap Defteri

Kişisel gelir-gider ve hesap bakiyesi takibi (nakit kasası, banka hesapları).
Alışveriş Listesi uygulamasında "Alışverişi bitir" denen alışverişlerin toplamını okur;
nakit ödenenleri varsayılan nakit hesabından, kartla ödenenleri varsayılan banka hesabından
otomatik gider olarak düşer.

- Veriler: Firebase Firestore, `hesaplar` ve `islemler` koleksiyonları (yalnızca sahibi erişebilir)
- Giriş: Google hesabı
- Yayın: GitHub Pages
